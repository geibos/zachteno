# Зачтено

[![easy-peasy-rust](https://img.shields.io/badge/style-easy--peasy-fecc02.svg)](https://github.com/skatromb/easy-peasy-rust)

Сервис тестирования студентов: курсы и тесты для методистов, потоки и результаты для преподавателей, прохождение тестов для студентов.

- Бэкенд: Rust (axum, sqlx, PostgreSQL), хранилище картинок — Garage (S3).
- Фронтенд: SvelteKit (статическая сборка, раздаётся бэкендом).
- Требования и решения: [`openspec/changes/add-student-testing-platform/`](openspec/changes/add-student-testing-platform/).

Стенд: https://zachteno.sobieg.ru
