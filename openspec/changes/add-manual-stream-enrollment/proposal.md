# Proposal

## Why

Сейчас студент попадает в поток только сам, по пригласительной ссылке. Преподаватель не может собрать группу по списку из деканата или добавить одного опоздавшего, не пересылая ему ссылку, а ссылку легко переслать дальше.

## What Changes

- Менеджер потока добавляет в поток уже зарегистрированных пользователей по email: одного или списком.
- По каждому адресу возвращается итог: добавлен, уже в потоке, возвращён из исключённых, не найден, некорректный адрес.
- Пользователи с неподтверждённым email добавляются, но в итоге и в списке участников отмечены отдельно.
- Каждое ручное добавление записывается в аудит-лог.
- На странице потока появляется форма «Добавить студентов» со списком адресов и отчётом.
- Аккаунты для незарегистрированных адресов не создаются: таким студентам по-прежнему нужна ссылка.

## Impact

- Бэкенд: новый эндпоинт `POST /api/streams/{stream_id}/members`, без изменений схемы БД.
- Фронтенд: форма на вкладке «Участники» потока, обновлённые OpenAPI-типы.
- Аудит: новое действие `stream.add_members`.
