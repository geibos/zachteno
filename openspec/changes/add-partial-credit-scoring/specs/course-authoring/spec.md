## MODIFIED Requirements

### Requirement: Вопросы
Тест SHALL содержать упорядоченный список вопросов трёх типов: одиночный выбор, множественный выбор, свободный ответ. Для множественного выбора методист выбирает один из режимов оценки: «только все», «хотя бы один», «балл за каждый верный», «доля верных». Тип вопроса и режим оценки выбираются в одном списке, который стоит в начале формы вопроса рядом с весом. Рядом с весом показывается максимальный балл вопроса.

У вопроса с одиночным выбором MUST быть ровно один верный вариант. У вопроса с множественным выбором в любом режиме — минимум один верный вариант и минимум два варианта всего. У вопроса со свободным ответом вариантов нет. Опубликовать тест, в котором есть вопрос, нарушающий эти правила, нельзя.

#### Scenario: Нет верного варианта
- **WHEN** методист публикует тест с вопросом множественного выбора, где не отмечен ни один верный вариант
- **THEN** публикация отклоняется с указанием проблемного вопроса

#### Scenario: Выбор режима частичного начисления
- **WHEN** методист открывает вопрос и выбирает в списке типа «Несколько: балл за каждый верный»
- **THEN** вопрос сохраняется в этом режиме, а рядом с весом показан максимальный балл, равный весу, умноженному на число верных вариантов
