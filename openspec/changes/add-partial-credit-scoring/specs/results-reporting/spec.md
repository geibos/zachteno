## ADDED Requirements

### Requirement: Процент в отчётах
Рядом с баллом попытки и итоговым баллом SHALL показываться процент: в таблице результатов теста — процент попытки и итоговый процент, в сводной таблице курса — итоговый процент по каждому тесту. В CSV-выгрузке результатов теста есть отдельные колонки с процентом попытки и итоговым процентом.

#### Scenario: Таблица результатов
- **WHEN** преподаватель открывает результаты теста, где студент набрал 93 из 93
- **THEN** в строке рядом с баллом показано 100 %

#### Scenario: CSV
- **WHEN** преподаватель выгружает результаты теста в CSV
- **THEN** в файле есть колонки с процентом попытки и итоговым процентом

## MODIFIED Requirements

### Requirement: Статистика по вопросам
Для каждого теста SHALL показываться статистика по вопросам, построенная по итоговым попыткам с учётом фильтра по потоку:
- число ответивших;
- доля полностью верных ответов — ответов, получивших максимальный балл вопроса;
- доля пропусков;
- средний балл;
- для вопросов с выбором — как часто выбирали каждый вариант.

Рядом со статистикой всегда показывается размер выборки.

#### Scenario: Подозрительный вопрос
- **WHEN** неверный вариант выбрали чаще, чем верный
- **THEN** методист видит это в распределении выборов по вариантам этого вопроса

#### Scenario: Частично верный ответ
- **WHEN** у вопроса в режиме «балл за каждый верный» с весом 1 три верных варианта, и студент получил за него 2
- **THEN** ответ не входит в долю полностью верных, а средний балл учитывает 2
