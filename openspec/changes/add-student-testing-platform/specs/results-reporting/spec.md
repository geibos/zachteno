# Spec Delta

## Purpose

Инструменты преподавателя и методиста для анализа результатов: таблицы по тесту и по курсу, детали попытки, экспорт в CSV и статистика по вопросам.

## ADDED Requirements

### Requirement: Таблица результатов теста
Преподаватель курса и методист SHALL видеть по каждому тесту таблицу.
- Строки: студенты.
- Столбцы: поток, номер попытки, время начала, время сдачи, длительность, способ сдачи (вручную, по времени, при закрытии окна), балл попытки, итоговый балл и по столбцу на каждый вопрос.
- Ячейка вопроса: балл и выбранные варианты либо текст свободного ответа.

Таблицу можно фильтровать по потоку, сортировать по любому столбцу и переключать между режимами «только итоговая попытка» и «все попытки». Участники, у которых есть сигналы антифрода, отмечены значком.

#### Scenario: Фильтр по потоку
- **WHEN** преподаватель выбирает в фильтре один поток
- **THEN** в таблице остаются только участники этого потока

#### Scenario: Свободный ответ в таблице
- **WHEN** в тесте есть вопрос со свободным ответом
- **THEN** в его столбце показан текст ответа целиком (через раскрытие ячейки) и пометка «не оценивается»

### Requirement: Сводная таблица курса
Преподаватель курса и методист SHALL видеть сводную таблицу курса: строки — студенты, столбцы — тесты, в ячейках — итоговые баллы и максимальный балл. Таблицу можно фильтровать по потоку.

#### Scenario: Несданный тест
- **WHEN** студент не сдал ни одной попытки по тесту
- **THEN** ячейка пустая с пометкой «нет попыток»

### Requirement: Детали попытки
Из таблицы SHALL открываться детали попытки: каждый вопрос с ответом участника, правильным ответом и баллом, журнал событий попытки и сведения о сигналах антифрода.

#### Scenario: Открытие попытки
- **WHEN** преподаватель нажимает на строку попытки
- **THEN** он видит ответы по вопросам и хронологию событий попытки

### Requirement: Экспорт в CSV
Таблицу теста и сводную таблицу курса SHALL можно выгрузить в CSV с теми же фильтрами и тем же режимом попыток, что выбраны на экране. Файл MUST быть в кодировке UTF-8 с BOM и разделителем `;`. Значение ячейки, которое начинается с `=`, `+`, `-`, `@`, табуляции или возврата каретки, MUST экранироваться, чтобы табличный редактор не исполнил его как формулу. Факт выгрузки записывается в аудит-лог.

#### Scenario: Открытие в Excel
- **WHEN** преподаватель открывает выгрузку в Microsoft Excel с русской локалью
- **THEN** кириллица отображается корректно, данные разложены по столбцам

#### Scenario: Формула в ответе
- **WHEN** свободный ответ студента начинается с `=HYPERLINK(`
- **THEN** в CSV значение экранировано и показывается как текст

### Requirement: Статистика по вопросам
Для каждого теста SHALL показываться статистика по вопросам, построенная по итоговым попыткам с учётом фильтра по потоку:
- число ответивших;
- доля полностью верных ответов;
- доля пропусков;
- средний балл;
- для вопросов с выбором — как часто выбирали каждый вариант.

Рядом со статистикой всегда показывается размер выборки.

#### Scenario: Подозрительный вопрос
- **WHEN** неверный вариант выбрали чаще, чем верный
- **THEN** методист видит это в распределении выборов по вариантам этого вопроса
