# Design

## Context

Панель собирает тесты одним запросом по потокам студента и раскладывает их по группам в `group`; тест без открытого окна, без расписания и без сданных попыток сейчас отбрасывается.

## Decisions

- **Новая группа вместо изменения существующих.** `closed` заполняется тем, что `group` сейчас отбрасывает; остальные группы не меняются, клиенты старых полей не ломаются.
- **Потоки — отдельным полем `streams`** (названия активных потоков), отдельный лёгкий запрос: нужен только для пустого состояния.
- **Ссылка — на существующую страницу старта** `/tests/{id}/start`. Права проверяет сервер, как и раньше; новой сущности или токена не нужно.

## Risks / Trade-offs

- Студент видит названия тестов до открытия окна. Названия тестов не секрет, а содержимое вопросов до старта попытки по-прежнему недоступно.
