# Proposal

## Why

Курс, назначенный потоку, сам тесты не открывает: их открывает преподаватель. Пока окно закрыто, студент видит пустую панель с советом перейти по пригласительной ссылке, хотя он уже в потоке, — и непонятно, записан ли он вообще. Преподавателю, в свою очередь, нечем поделиться: прямой ссылки на тест нет.

## What Changes

- На панели студента появляется группа «Пока закрыты»: опубликованные тесты его курсов, у которых окно для его потока закрыто и не запланировано.
- Панель знает потоки студента: если тестов нет, она называет поток и объясняет, что тесты откроет преподаватель, вместо совета про пригласительную ссылку.
- В блоке окон на странице теста — кнопка «Скопировать ссылку для студентов» на страницу старта теста и подсказка под закрытым окном.
