## ADDED Requirements

### Requirement: Закрытые тесты и потоки на панели студента
Панель студента SHALL показывать группу «Пока закрыты»: опубликованные тесты курсов его потоков, у которых окно для его потока закрыто, время открытия не назначено и сданных попыток нет. Начать такой тест MUST NOT быть можно. Панель SHALL знать потоки, в которых студент состоит: если тестов в потоках нет, панель называет потоки и объясняет, что тесты откроет преподаватель. Совет перейти по пригласительной ссылке показывается только студенту, который не состоит ни в одном потоке.

#### Scenario: Курс назначен, окно не открыто
- **WHEN** студент состоит в потоке, которому назначен курс с опубликованным тестом, а окно для потока закрыто и не запланировано
- **THEN** тест виден в группе «Пока закрыты» без кнопки начала

#### Scenario: В потоке, но тестов нет
- **WHEN** студент состоит в потоке, которому ещё не назначен курс с опубликованными тестами
- **THEN** панель называет поток и сообщает, что тесты появятся, когда преподаватель их откроет

### Requirement: Прямая ссылка на тест
Преподаватель и методист SHALL иметь возможность скопировать прямую ссылку на страницу старта теста, чтобы отправить её студентам. Ссылка MUST NOT давать доступа сама по себе: открыть тест по ней может только участник потока, которому назначен курс; начать попытку — только при открытом окне.

#### Scenario: Ссылка из блока окон
- **WHEN** преподаватель нажимает «Скопировать ссылку для студентов» на странице теста
- **THEN** в буфер обмена попадает адрес страницы старта этого теста

#### Scenario: Студент открывает ссылку
- **WHEN** участник потока открывает ссылку на тест, окно которого закрыто
- **THEN** он видит страницу теста с пояснением, что тест пока закрыт, а начать попытку не может
